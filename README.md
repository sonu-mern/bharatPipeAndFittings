# Bharat Pipe & Fittings - React SSR Application

A modern React application with Server-Side Rendering (SSR) for Bharat Pipe & Fittings, a leading manufacturer of industrial pipes, fittings, and related products in India.

**🌐 Live Website**: https://www.bharatpipeandfittings.com

## 🚀 Features

- **Server-Side Rendering (SSR)** for better SEO and performance
- **Responsive Design** optimized for all devices
- **SEO Optimized** with comprehensive meta tags and structured data
- **Fast Loading** with optimized assets and caching
- **Modern UI** built with React and Tailwind CSS
- **Product Catalog** with detailed product pages
- **Contact Integration** with WhatsApp and email
- **Trusted by** major industrial clients

## 🛠️ Technical Stack

- **Frontend**: React 18 with TypeScript
- **SSR**: Vite + Express.js
- **Styling**: Tailwind CSS + CSS Modules
- **Deployment**: Vercel with custom domain
- **SEO**: React Helmet Async
- **Routing**: React Router DOM
- **UI Components**: Shadcn/ui

## 📁 Project Structure

```
src/
├── components/          # Reusable UI components
├── pages/              # Page components
├── utils/              # Utility functions
├── assets/             # Static assets
├── entry-client.jsx    # Client-side entry point
├── entry-server.jsx    # Server-side entry point
└── App.tsx            # Main application component
```

## 🚀 Deployment

The application is deployed on Vercel with the following configuration:

- **Domain**: https://www.bharatpipeandfittings.com
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Runtime**: Node.js 18.x
- **SSR**: Enabled with custom API function
